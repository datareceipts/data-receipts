Data Receipts

Don't trust the video. Run the script.

Original data analysis on cloud pricing, AI costs, and the economics of building software — where the numbers come from primary sources, not from someone else's blog post.

The method

  • Primary sources onlyPrices come from vendor pricing APIs. Wages come from government statistical releases. Token counts come from running the thing and measuring it.
  • Every number is reproducibleThe dataset and the collection script for each video are published. You can re-run them and get the same figures, or find out that I was wrong.
  • Comparisons are normalisedFree tiers, regional differences and billing-unit mismatches are reconciled before anything is compared, and the adjustments are documented.
  • Unmeasurable claims get cutIf a number can't be sourced or measured, it doesn't go in the video — even when it would make a better headline.
