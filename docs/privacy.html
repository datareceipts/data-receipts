Privacy Policy

Last updated 2 November 2026

This policy covers two things: this website, and the private application used to publish videos to the Data Receipts YouTube channel.

This website

This site is a set of static pages. It sets no cookies, runs no analytics, embeds no trackers, and has no accounts, forms or comment system. Nothing you do here is recorded by us.

The site is hosted on GitHub Pages. As the host, GitHub receives standard web server request data such as your IP address and browser user agent. That data is handled under GitHub's privacy statement and is not accessible to us.

The publishing application

Video publishing and analytics review are automated by a private command-line application that is not distributed and has no users other than the channel operator. It authorises against Google using OAuth 2.0 and requests these scopes:

  • youtube.upload — to upload video files to the operator's own channel.
  • youtube — to set titles, descriptions, tags and thumbnails on those uploads.
  • yt-analytics.readonly — to read performance statistics for the operator's own channel.

What the application does with that access

  • It accesses exactly one YouTube channel: the operator's own.
  • It reads aggregate channel statistics — views, watch time, average view duration, traffic sources. These contain no information identifying individual viewers, and no viewer-level data is ever requested.
  • Its OAuth credentials are stored only on the operator's own computer, in a file readable solely by that user account, and are excluded from version control.
  • Nothing obtained through these scopes is sold, shared, transferred, or used for advertising or profiling. There is no server, no database, and no third party receiving any of it.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Published datasets

The datasets published alongside each video contain vendor pricing figures, public statistical releases, and measurements taken from software run by the operator. They contain no personal data. Where raw output could include local system details such as file paths or usernames, those are removed before publication.

Children

This content is made for a professional and adult audience. The channel is not directed to children and no information is knowingly collected from them.

Changes

If this policy changes, the revised version will be posted here with an updated date.
